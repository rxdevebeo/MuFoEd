# image-gallery — галерея изображений с пакетной обработкой

Встраиваемый компонент egui 0.35 для MuFoEd: будущая вкладка «Галерея».
Основа галереи — выбранная папка: превью всех читаемых изображений,
большой просмотр, свойства файла и EXIF. Команды ленты работают с одним
файлом или с выделением: конвертация, повороты, отражения, изменение
размера, кадрирование, холст, цветокоррекция, удаление метаданных,
переименование по шаблону, копирование и перенос.

Крейт не зависит от библиотечных крейтов StrictLib и не использует нативных
библиотек изображений: всё на чистом Rust.

## Форматы

| Формат | Чтение | Запись | Замечания |
|---|---|---|---|
| PNG / APNG | да | да | APNG — первый кадр |
| JPEG | да | да | качество; поворот без потерь через EXIF |
| WebP | да | да | запись только без потерь (image-webp) |
| GIF | да | да | первый кадр |
| TIFF | да | да | |
| BMP, ICO, TGA | да | да | ICO уменьшается до 256 px |
| PNM (PBM/PGM/PPM/PAM) | да | да | |
| QOI, Farbfeld | да | да | |
| OpenEXR, Radiance HDR | да | да | на экране — с кривой sRGB |
| DDS | да | — | |
| AVIF | — | да | запись через rav1e; чтение требует нативного dav1d |
| JPEG XL | да | — | jxl-oxide |
| SVG / SVGZ | да | — | resvg, системные шрифты; масштаб в рецепте |
| PSD / PSB | да | — | сведённое изображение: Bitmap, Gray, Indexed, RGB, CMYK, Lab, Multichannel, Duotone; 1/8/16/32 бит; RAW/RLE/ZIP |
| Camera RAW | да | — | встроенное полноразмерное JPEG-превью: DNG, CR2, CR3, CRW, NEF, NRW, ARW, SR2, ORF, RW2, RAF, PEF, ERF, 3FR, IIQ, SRW, X3F и др. |
| HEIF / HEIC | — | — | распознаётся и помечается: декодера на чистом Rust нет |

Формат определяется по содержимому, расширение лишь подсказывает. ICC-профиль
и EXIF переносятся при конвертации туда, где формат их хранит (JPEG, PNG, WebP,
AVIF). При автоповороте по EXIF ориентация в копии сбрасывается в «прямо»,
чтобы файл не повернулся дважды. Демозаика сенсорных данных RAW не
выполняется — нужен RAW-конвертер; показывается и конвертируется превью
камеры.

## Операции

Рецепт — список операций и настройки вывода; сохраняется в JSON.

- поворот на 90°/180°, отражение, поворот на произвольный угол с расширением холста;
- изменение размера: вписать в рамку, заполнить рамку (с обрезкой), точный
  размер, ширина, высота, длинная/короткая сторона, проценты; фильтры
  Nearest/Bilinear/Bicubic/Gaussian/Lanczos; «не увеличивать меньшие»;
- кадрирование: пропорции с привязкой, прямоугольник, поля, обрезка однотонных полей;
- холст: размер, пропорции, рамка, цвет и прозрачность;
- яркость, контраст, насыщенность, гамма, оттенок, оттенки серого, сепия,
  негатив, автоуровни, размытие, резкость, удаление прозрачности;
- внешние инструменты хоста (`Operation::Tool`) — точка подключения
  инструментов на моделях, например удаления фона.

Вывод: формат (или «оставить»), качество JPEG/AVIF, сжатие PNG, фон для
форматов без прозрачности; папка (та же, подпапка, выбранная); шаблон имени
`{name} {n:3} {date} {time} {w} {h} {camera} {folder} {ext}`; конфликт имён
(добавить номер, пропустить, заменить); сохранение EXIF, ICC и даты
изменения; масштаб SVG.

Где результат можно получить без декодирования, так и делается: без
операций файл копируется побайтно; повороты и отражения JPEG записываются в
EXIF-ориентацию; удаление метаданных из JPEG и PNG выбрасывает сегменты и
чанки (ICC и ориентация остаются). Запись атомарная: через временный файл в
той же папке.

Готовые наборы: «Веб: JPEG, 1920 px», «Миниатюры 320 px», «Квадрат
1080 px», «Конвертировать в PNG/WebP/JPEG»; свои наборы сохраняются в
настройках.

## Встраивание

```rust
let mut gallery = image_gallery::Gallery::new(image_gallery::Locale::new("ru"));
// каждый кадр, внутри вкладки:
for event in gallery.show(ui) {
    match event {
        GalleryEvent::PickFolder => { /* диалог → gallery.open_folder(path) */ }
        GalleryEvent::PickDestination(purpose) => { /* диалог → gallery.set_destination(purpose, path) */ }
        GalleryEvent::OpenInEditor(path) => { /* открыть во вкладке редактора */ }
        GalleryEvent::Reveal(path) => { /* показать в проводнике */ }
        GalleryEvent::FolderOpened(_) | GalleryEvent::Written(_) => {}
    }
}
```

- `show_ribbon(ui)` и `show_content(ui)` — если хост рисует ленту в своей полосе;
- `execute(Command)` / `can_execute(Command)` — кнопки ленты хоста;
- `settings()` / `set_settings()` — сериализуемые настройки (размер превью,
  сортировка, рецепт, свои наборы, шаблон переименования);
- `register_tool(id, label, f)` — инструмент хоста, доступный в рецептах;
- ядро без UI: `decode::load`, `ops::Operation::apply`, `encode::encode`,
  `batch::Job::start` (рабочие потоки, прогресс, отмена).

Превью декодируются фоновыми потоками, видимые — в первую очередь; смена
папки отменяет старые запросы. Паники декодеров перехватываются и
становятся ошибкой файла.

## Клавиатура

Стрелки, Home/End, PageUp/PageDown — перемещение (Shift — расширить
выделение, Ctrl — только фокус); Ctrl+A — выделить всё; Enter — просмотр;
Esc — снять выделение / закрыть просмотр; F5 — обновить; Ctrl+R / Ctrl+L —
повернуть вправо / влево. В просмотре: ←/→, PageUp/PageDown, пробел; колесо —
масштаб к курсору; перетаскивание — сдвиг; двойной щелчок — 100 % / вписать;
0 — вписать.

## Запуск демонстрации

```powershell
cargo +1.92.0 run -p image-gallery --features demo --bin image-gallery-demo -- D:\Photos
```

Переменные окружения: `GALLERY_LANGUAGE=ru`, `GALLERY_SETTINGS=<файл.json>`
(чтение и запись настроек), `GALLERY_SHOT=<файл.png>` (снимок окна после
загрузки и выход).
