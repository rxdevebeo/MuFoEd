## Кодовые зазоры: доставка шрифта, A11

Две исходные строки — `Console.WriteLine("Welcome to coding");`: **0 tabs**, по одному обычному пробелу между словами, нет пробела у скобок. Run разделены из-за цвета: `Console.WriteLine(` / литерал / `);`.

Выбрана семья Cousine из `cs=Courier New`, предпочитаемого в `style.rs:315–329`, хотя ascii/hAnsi=Consolas. В странице 2 фрагмент `Console.WriteLine(` занимает **144,023 px**, x=71,867 → 215,890 при размере 13,333 px, что согласовано с моноширинным встроенным лицом. `paint/mod.rs:20–48` и `paint/text.rs:9–60` не встраивают шрифты. В проверенных Windows Fonts Cousine не найден; потребитель SVG должен получить ресурс отдельно.

Для примера последствий fallback: hmtx локального Times New Roman дает на этот фрагмент **106,260 px**, на **37,763 px** меньше выделенного расстояния; пробел около 3,333 px против примерно 8 px в Cousine. Это объясняет возможные зазоры между независимо позиционированными фрагментами. **Реально разрешенное лицо браузера пользователя не измерено**, Times приведен как количественный пример, а не установленный факт о пользовательском браузере. Источник и SVG подтверждают проблему доставки ресурсов; табуляцию как причину двух строк XML опровергает.
