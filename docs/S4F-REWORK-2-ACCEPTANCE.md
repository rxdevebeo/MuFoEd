## 4. Находки и остаточные замечания

### R-1 (значимое, B-3 частично). Горизонтальный сдвиг не детектируется

**Факт.** Структурный инвариант (`tests/ssim.rs`) ловит пустую страницу
(`ink`-ratio) и **вертикальный** дрейф (row-ink профиль), но **горизонтальная**
рассинхронизация не влияет на row-ink профиль и не ловится:

| воздействие на кандидат `strict-text` | SSIM | структурный инвариант |
|---|---|---|
| корректный | 0.9768 | PASS (shift 0, corr 0.975) |
| пустая страница | 0.9475 | reject (ink) |
| вертикаль 2 px | 0.9508 | PASS |
| вертикаль 3 px | 0.9473 | **reject** |
| горизонталь 3 px | 0.9531 | **PASS** |
| горизонталь 5 px | 0.9541 | **PASS** |
| горизонталь 8 px | 0.9549 | **PASS** |
| горизонталь 10 px | 0.9516 | **PASS** |

То же для `strict-text-grid`: горизонталь 3…10 px → SSIM 0.9441…0.9477 (< 0.95,
отклоняется SSIM-порогом), но для `strict-text` до ~10 px проходит **оба** гейта.
DoD B-3 сформулирован как «сдвиг ≥ 3 px отклоняется» — для горизонтали не
выполнено.

### R-2 (мелкое, документация). `STAGE-4-ACCEPTANCE.md` рассинхронизирован

- §1 (строка с «Покрытие render-svg») и §3 п.9 — «88.68 %» (устарело; факт
  **89.39 %**);
- §3 п.2 — «SSIM ≥ 95 % — ❌ waiver (эталоны/растеризатор отсутствуют)» —
  противоречит включённому enforced-гейту и записи «закрыто частично» выше по
  документу;
- статусная строка шапки всё ещё перечисляет «SSIM — waiver» без пометки
  «частично».

### B-2 (процессное, не код). Исключение требует подписи заказчика

Решение «реальный Strict — только инвариант страниц» корректно оформлено в
`STAGE-4-ACCEPTANCE.md`/ADR-0006/отчёте, но по тексту самого документа оно
**требует письменного согласования заказчика**. До согласования пункт открыт;
формулировка «O1 закрыт» к реальному Strict не применяется.

### Прочее (информационное)

- `docDefaults/pPrDefault` spacing по-прежнему не каскадируется (B-1b,
  задокументированное ограничение). Grid-правило от него не зависит, но при
  будущем добавлении каскада `docDefaults` нужно перепроверить `strict-profile`
  2/2.

## 7. Задание следующему агенту (что доработать)

> Только требования и критерии приёмки. Код не приводится.

### R-1. Чувствительность гейта к горизонтальному сдвигу

**Требование.**
1. Дополнить структурный инвариант (`tests/ssim.rs`) метрикой, чувствительной к
   горизонтальному смещению текста: например, **x-центроид** чернил (границы
   bbox по колонкам) и/или **колоночный ink-профиль** (коэффициент корреляции
   профилей колонок) с допуском в пикселях; при необходимости — NCC по области
   текста.
2. Порог подобрать так, чтобы корректный рендер проходил, а сдвиг `dx ≥ 3 px`
   отклонялся; метрика детерминирована и не зависит от растеризатора.
3. Контроль-тест (unit или integration): пустая страница, вертикальный сдвиг
   ≥ 3 px и горизонтальный сдвиг ≥ 3 px — **все** отклоняются; корректный — нет.
4. Синхронизировать документацию (ADR-0006/`refs/README.md`) — указать, что
   теперь проверяются обе оси.

**Критерии приёмки R-1.**
1. На реальном кандидате `strict-text` горизонтальное смещение `dx ∈ {3,5,8,10}`
   **отклоняется** гейтом; `dx = 0` проходит.
2. Вертикальный сдвиг ≤ 2 px проходит, ≥ 3 px отклоняется (без регрессии B-3).
3. Все `SSIM_DOCS` (`strict-text`, `strict-text-grid`) проходят без изменения
   порогов SSIM; `strict-profile` — 2/2.
4. Гейты fmt/clippy/test/doc/deny и покрытие render-svg ≥ 80 % — зелёные.

### R-2. Синхронизация `STAGE-4-ACCEPTANCE.md`

**Требование.** Привести документ в соответствие с фактами:

  Strict — инвариант страниц, исключение B-2»;
- статусная строка шапки — без устаревшего «SSIM — waiver».

**Критерий приёмки R-2.** В `STAGE-4-ACCEPTANCE.md` нет утверждений,
противоречащих включённому SSIM-гейту и статусу O1 «закрыт частично»; числа
