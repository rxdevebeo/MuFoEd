# Выделение китайского текста, корпус №064

Пользователь сообщил о подсветке, которая покрывает лишь части строк китайского
текста. Причина найдена в `strict-ooxml-edit/src/visual.rs`: карта повторно
измеряла префиксы через `shape_text`/обычный FontProvider, тогда как отрисовка
использовала `shape_run` с подключённой шрифтовой программой. Для китайских
резервных шрифтов это давало другие ширины. Также не учитывались все параметры
межсимвольного интервала и горизонтального масштаба.

С согласия пользователя изменена только карта редактирования в рабочем дереве:

- Координаты берутся из формирования всего нарисованного фрагмента с его
  реальным шрифтом; повторного формирования каждого префикса для обычного
  текста больше нет.
- Учитываются кластерные координаты, межсимвольные интервалы, сжатие пробелов
  и горизонтальный масштаб. Конечная граница совпадает с размещённой шириной.
- Вертикальная область использует метрики подключённой шрифтовой программы.
- Для RTL сохранено прежнее соглашение карты о логической ширине; эта работа
  не заявляет исправление двунаправленного выделения.

## Проверки

Использован существующий автономный OFL-шрифт
`strict-ooxml-render-svg/fonts/witnesses/cjk.otf`; установка системного шрифта
или исходного корпуса для регрессий не требуется.

1. Шесть китайских знаков с шириной ровно 1 em: границы каретки, ширина
   выделения каждого знака и hit-test. Проверены масштаб 100%/80% и интервал
   30 twips.
2. Смешанная строка `AV漢字中文`: координаты каретки сравниваются с координатами
   символов в действительно сгенерированном SVG, с интервалами и масштабом.
3. Полный набор `strict-ooxml-edit`: 141 PASS, включая 20 визуальных регрессий.
4. MuFoEd: 106 PASS, 6 существующих ignored.
5. Clippy `strict-ooxml-edit`, all-targets, `-D warnings`: PASS.
6. Release MuFoEd: успешная сборка, `target/release/mufoed.exe`.

Проверки подтверждают исправление геометрии на автономных китайских и смешанных
образцах. Интерактивное выделение полного №064 в GUI после этой сборки остаётся
для пользовательской проверки. Текст и структура документа не изменяются.
Служебный текст TeX, видимый на снимке, относится к отдельным ограничениям импорта.

Логи сохранены в `target/cjk-edit-tests.log`, `target/cjk-visual-tests.log`,
`target/cjk-edit-clippy.log`, `target/cjk-mufoed-tests.log`,
`target/cjk-mufoed-build.log`.
Основной каталог `D:/projects/StrictLib` не изменялся; коммит не создавался.
