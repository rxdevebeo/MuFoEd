# U01–U05: стандартные контракты и приёмка

Дата: 2026-10-22. Рабочее дерево `codex/image-studio`, база `43b36138284e74f4a554ca2cb45f5318facfecd3`. Изменения ограничены `image-editor/`; StrictLib, MuFoEd и общий model-runtime не менялись. Коммит не создавался.

## Принятые решения

| Пункт | Поведение |
|---|---|
| U01 | Вставка локально смешивает серое значение маски с прежним значением по альфе фрагмента. Вне фрагмента и в прозрачных отверстиях покрытие сохраняется. Полная замена маски остаётся явной операцией; дополнительные переключатели Add/Subtract для обычной вставки не вводились. |
| U02 | Opacity ограничивает весь жест кисти, ластика и ретуши. Максимальное покрытие вычисляется относительно неизменного источника жеста. Повтор кадра, пересечение и коллинеарное разбиение маршрута не усиливают один мазок. Следующий мазок накапливает результат. Обычный Flow100%, без отдельного аэрографа. |
| U03 | Ctrl+T сохраняет плавающую вставку и трансформирует только её пиксели, включая текущий слой и обе цели маски. Предпросмотр не меняет документ. Применение возвращает к размещению; Enter закрепляет вставку. Отмена трансформации сохраняет вставку, отмена вставки возвращает исходный документ. Вся последовательность даёт один Undo. |
| U04 | Savepoint — SHA256 содержимого, а не флаг «был вызван edit». Undo/Redo сравнивают с сохранённой точкой. Активный слой и обычное выделение исключены, маски/пиксели/свойства/recipe включены. Обрезанная история не создаёт ложную чистую точку. Recovery требует явного Save. |
| U05 | Default VAE берётся из выбранного checkpoint и на CPU, и на GPU. SDXL VAE вычисляется в FP32. Явный Request.vae имеет приоритет. Сначала проверяются локальные варианты файлов. Конвертер v4 сохраняет provenance и больше не публикует checkpoint VAE под чужим глобальным именем. Старый CLI вызывает тот же конвертер; --vae готовит отдельный override и возвращает его путь. Старый пользовательский кэш не меняется. |

- PSD exact recipe/layers/masks/selection roundtrip продолжает проходить в полном suite. Формат PSD не расширялся.
