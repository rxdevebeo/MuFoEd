# UI03 — вкладки документов и файловый host

База: `7f3a81f06b1e55eacfdc2c310a8595378749ee81` (master после слияния image-studio). Работа продолжается в `codex/image-studio`; изменения только в `image-editor/`. Новые коммиты не создавались.

## Контракт

- Каждый PNG/JPEG/WebP/BMP/TIFF/PSD/legacy JSON открывается как отдельный документ. Multi-select в системном диалоге, drag-and-drop и несколько путей в CLI/BAT поддерживаются. Неиспользованный стартовый холст переиспользуется; изменённый документ не заменяется. Повторный путь активирует уже открытую вкладку.
- У вкладки собственные ImageEditor, Undo/Redo, слои/маски/выделение, масштаб/pan, текст промптов и результаты. ID стабильны при закрытии соседей. Команды моделей используют существующий общий Runtime. Переключение завершает мазок/изменение свойства и останавливает drag без сброса положения холста.
- Открытый PSD хранит путь для Ctrl+S. Для растра, legacy JSON и нового документа Ctrl+S выбирает новый PSD. Ctrl+Shift+S всегда выбирает путь. После успешного атомарного save обновляются путь и savepoint только нужной вкладки; ошибка и Cancel не закрывают её. Нельзя через Save перезаписать растр или файл другой открытой вкладки. Export PNG не снимает dirty.
- Ctrl+N/O/S/Shift+S/W работают и при фокусе текстового поля; диалоги редактора сохраняют владение клавиатурой. Ctrl+Tab/Shift+Tab, крестик, средняя кнопка и контекстное меню управляют вкладками. Есть Save All, Close Others и Close All; отмена останавливает оставшуюся очередь.
- Закрытие окна последовательно проверяет все документы. Для dirty и работающих задач требуется решение; неприменённый результат отдельно предупреждает о потере и требует вернуться к принятию результата перед сохранением. Закрытие отменяет собственные задачи вкладки, не выгружая общий кэш из-за простого переключения/закрытия файла.
- Preferences общие, применяются к свободным редакторам с сохранением их промптов/режима. Настройки нового свободного редактора можно применить во время чужого inference. Собственные активные операции защищены от изменения настроек.
- Recovery writer отдельный на вкладку. Удаление/очистка одной сессии не затрагивает остальные. Startup discovery выполняется один раз; несколько копий восстанавливаются новыми вкладками и не заменяют уже открытые файлы. Закрываемые сессии дожидаются завершения записи и очистки.

## Регрессии

Пять тестов workspace: dirty/document identity и повторное открытие; save-as, исходник и конфликт путей; error/cancel/batch-close/window-close; независимый Undo и общие настройки; направления Ctrl+Tab/Ctrl+Shift+Tab и блокировка диалогом.

Два host API теста: файловые shortcuts с текстовым фокусом/окном настроек; background polling без автоматического принятия результата, отдельные редакторы и сохранение preferences при отмене.

Два recovery теста: независимость writers при сохранении/закрытии соседней вкладки; последовательная передача двух startup-копий без потери первой.
