# Выделение, буфер обмена и inpaint prompt

Выполнено в image-editor существующего worktree codex/image-studio. StrictLib/model-runtime не менялись, прежнее исправление SD1.5 Hires сохранено. Новый коммит не создавался.

## Поведение

Прямоугольное выделение M, лассо L, кисть/ластик маски Q/Shift+Q и результат SAM используют общую маску Document. Лассо рисуется с предпросмотром, замыкается при отпускании и заполняется по правилу even-odd на центрах пикселей. Escape отменяет незавершённый контур без изменения маски. Линия перенесена на Shift+L. Ctrl+A выделяет всё, Ctrl+D очищает маску.

Copy активного слоя/видимого сведения использует минимальные bounds выделения; пустая маска означает весь холст. RGB остаётся straight-alpha, исходный alpha умножается на soft coverage один раз, прозрачные пиксели очищаются. Copy не меняет Document/Undo. Ctrl+C — выбранный источник, Ctrl+Shift+C — сведение. Буфер переживает replace проекта в одном виджете; для нового документа позиция сбрасывается в0/0.

Ctrl+V/кнопка вставляют отдельный прозрачный полноразмерный слой; Ctrl+Shift+V/кнопка — source-over в текущий слой. Блокировка и лимит16 слоёв соблюдаются, отрицательные координаты и края обрезаются, полностью внешняя вставка отклоняется без изменений. Исходная маска не обрезает вставку повторно. X/Y задаются в раскрываемом разделе позиции. Вставка — одна обратимая операция; clipboard не является частью PSD/Undo.

Demo включает native-clipboard/arboard3.7.0 для RGBA-системного буфера; без feature доступен внутренний буфер и PixelClipboard API для хоста. Ошибка записи в системный буфер оставляет рабочий внутренний. egui-winit поглощает Ctrl+V key-down для текста, поэтому для изображения обрабатывается также key-up; специальный флаг предотвращает двойную вставку. Текстовые поля имеют приоритет над canvas shortcuts.

В Edit над инструментами моделей размещены промпт перерисовки маски, раскрываемый negative prompt, strength, инверсия и показ маски. Поля меняют тот же Request, который клонируется PipelineJob; отдельный UI-only prompt не создавался. Модели/LoRA остаются в Settings.

## Уточнение копирования и размещения (2026-10-21)

Перед копированием выбирается «Изображение / Маска». Маска копируется отдельным типом: непрозрачный grayscale в системном буфере и признак маски во внутреннем. Её вставка заменяет общую маску, не затрагивая слои или их блокировки. Покрытие 0/64/128/255, отверстия, исходная позиция и обрезка проверены тестами. Пустая маска отклоняется.

После вставки включается Hand. ЛКМ в рамке двигает только вставленный объект, ПКМ двигает холст. Для вставки в текущий слой сохранён исходный фон; повторное движение не накапливает наложения alpha и не сдвигает весь слой. Фрагмент сохраняется целиком до закрепления, включая части за краем холста. Enter/кнопка закрепляет, Escape отменяет вставку. Выбор инструмента, слоя или дальнейшая операция завершает размещение; проверка текущего документа предотвращает перезапись сторонних изменений. Undo/Redo охватывает вставку с конечным положением.

Проверки: строгий Clippy с demo,plakat-cudnn,ollama PASS; полный набор тестов: 133 passed, 2 ignored, 0 failed. Тесты UI воспроизводят ЛКМ drag при zoom8, восстановление фона, ПКМ pan, Enter и последующий обычный Hand pan, Escape, Undo/Redo для обоих типов вставки. Системный clipboard в тестах не изменялся; межприложенческий roundtrip отдельно не проверялся.

Release demo+plakat-cudnn собран из окончательных исходников. Оба нативных GUI-запуска завершились exit0, просмотрены снимки 1440×900 и 1100×700; настройки изолированы. ## Единый режим Растр / Маска (2026-10-21)

Переключатель вынесен в верхнюю общую полосу, Q меняет режим, сохраняя текущий инструмент. Выбор типа в буфере и отдельные mask brush/eraser из палитры удалены. Совместимые API-псевдонимы ManualTool::Mask/Unmask выбирают обычную кисть/ластик и цель Mask. Переключение не изменяет документ, хранит цвета двух режимов раздельно, завершает текущий жест/размещение и отменяет незакреплённый диалог коррекции или трансформации.

Общие кисть, ластик, bucket fill, gradient, line/rectangle/ellipse, Move, Eyedropper, фильтры, коррекция и трансформация следуют EditTarget. Маска редактируется теми же растровыми алгоритмами в grayscale-представлении; изменяется только покрытие, блокировки слоёв не мешают. Документный edit_mask транзакционен, структурные операции отвергаются. Общая геометрия холста и команды структуры слоёв сохраняют явные назначения. GPU mesh preview трансформации маски накладывается на исходный растр без изменения документа до Apply.

Copy и Paste следуют только текущему режиму. При вставке изображения в маску используется Rec.709 luminance × straight alpha; при вставке маски в растр она становится непрозрачным grayscale. Размещение Hand и единый Undo сохранены. Межприложенческий roundtrip буфера отдельно не проверялся.

Проверки: 139 passed, 2 ignored, 0 failed; строгий Clippy demo,plakat-cudnn,ollama PASS. В тестах одинаковые pointer-жесты выполняются восемью общими инструментами для обоих режимов с Undo и проверкой неизменности другого содержимого. Дополнительно проверены mask Eyedropper, цвета, отсутствие Undo на переключении, конвертация обоих типов вставки, коррекция/трансформация маски при заблокированном слое, полный UI-путь GPU overlay и отмена предпросмотра при смене режима, откат ошибок edit_mask.
