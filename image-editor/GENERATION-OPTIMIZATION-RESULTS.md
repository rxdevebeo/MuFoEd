# Ускорение генерации: результаты

Изменения выполнены в image-editor отдельного worktree codex/image-studio. Исходники StrictLib и общего model-runtime не менялись. Коммиты не создавались.

## Полный цикл, одинаковое задание

RTX 5070 Ti, SDXL local/image-studio-sdxl: 1024² → UltraSharp 1536² → Img2Img 1536². DPM++ 2M Karras, seed42, CFG7.5/6, 50 шагов первого прохода, расписание20/denoise0.3 второго (6 фактических шагов). Model, prompt/negative, LoRA (нет в основном эталоне), VAE, размеры, tile256 и порядок этапов совпадают: request из receipts проверен на полное равенство.

Каждая версия запускалась отдельным процессом: cold runtime cache + 5 warm. OS file cache не очищался. Старый бинарник сохранён до изменений, новый собран с cargo-performance.toml и cuDNN. Серии выполнялись последовательно без компиляции и параллельных inference-тестов. Для обоих основных рядов диагностика включена. CUDNN_CONV_WSCAP_DBG не установлен: экспериментальный workspace cap не входит в поставку и не нужен для результата.

## Реализация и ресурсы

- cuDNN-свёртки через feature plakat-cudnn; локальная настройка DLL/import library в scripts/enter-cudnn.ps1. Launcher автоматически выбирает этот путь при наличии cuDNN9, иначе сообщает о CUDA fallback. Ручной fallback: start.bat -LegacyCuda.
- Постоянный inference-поток и CUDA device на физический UUID устраняют повторную инициализацию и выявленный Windows-сбой TLS cuDNN при завершении временного потока. CUDA context живёт до выхода процесса. Поток не удерживает lease или модельные тензоры в idle.
- Подготовленные CPU tensors кэшируются по fingerprint/dtype/LoRA signature/device; builder выполняет только перенос. FP32 VAE не заменён FP16. Его cache bytes исправлены с167307726 на334615452.
- CLIP conditioning хранится на CPU как Resource того же общего Runtime. Ключ включает оба prompt, CFG-ветвь, encoder/LoRA/tokenizer fingerprints, dtype и device. В 12 native-проходах основного ряда CLIP compute был выполнен один раз. Размер и SDXL time_ids задаются отдельно для каждого прохода.
- Для >1MP введено точное разбиение attention по двум головам; весь softmax по keys сохранён. Исправлены concat/remainder в трёх локальных модулях закреплённого Plakat. Лицензии, upstream SHA и изменения описаны в src/generation/plakat_unet/NOTICE.md и UPSTREAM.json. Plakat остаётся Git-зависимостью; Flash/fused SDPA под Windows sm120 не включён.
- VRAM admission согласован с фактически ограниченным attention workspace. Защитный резерв не уменьшен. Большие задания, например SDXL2048² с оценкой14GiB, по-прежнему могут быть отклонены. Общий model-runtime сохраняет владение очередью, admission, eviction и unload для изображений и текста.

Наблюдения CUDA free/total с интервалом20ms во всём новом основном ряду: min_free UNet5.776GiB, VAE decode7.964GiB; невалидных samples0. Максимальный прирост занятости от начала UNet-наблюдения8.813GiB, decode6.281GiB. Это выборочные наблюдения, не абсолютный allocator high-water mark; общий фон GPU включён в free VRAM. Физически невозможные значения nvidia-smi не использованы.

## Изолированная проверка VAE и численная точность

На одинаковых sine latents1×4×128×128, FP32, full decode1024², cold+5warm: старый путь7.480/7.652/6.365/6.178/6.261/6.268с; cuDNN1.232/0.890/0.897/0.888/0.890/0.891с. В старом пути наблюдался min_free0 во всех шести decode, новый сохранял около8GiB. Исходный Candle CUDA conv2d использует im2col с крупными промежуточными буферами; замена backend устраняет измеренный дефицит свободной VRAM. WDDM paging напрямую не трассировался и не объявляется доказанным механизмом задержки. В этой отдельной ранней пробе был установлен экспериментальный cap256MiB; основной итоговый A/B проведён без него.

На фиксированных latents mean_abs выходаVAE=0.00002308, max_abs=0.007377, RMSE=0.00003766. Максимальная разница соответствует менее1 уровня RGB8 при преобразовании [-1,1] в [0,255]. cuDNN не гарантирует побитовую идентичность прежним CUDA-свёрткам; в diffusion малые численные отличия могут менять детали. Оба полных ряда детерминированы внутри своей версии: один pixel SHA256 на шесть запусков, но SHA между версиями различается. Визуально просмотрены обе1536² картинки: композиция, цвет, фактура и контуры натюрморта сохранены, рисунок орнамента немного отличается. Это ограниченная визуальная проверка, не универсальная гарантия качества всех checkpoints.

Независимые CPU-тесты сравнивают sliced self/cross attention, CFG batch1/2, неполные группы3heads и полный UNet bridge с исходным Plakat, включая pooled/time_ids SDXL. Топология и имена весов не менялись. Fused attention, VAE FP16, quantization и UltraSharp FP16 ради скорости не применялись.
