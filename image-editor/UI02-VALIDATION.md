# UI02 — компактная лента, палочка, миниатюры и настройки

База: `43b36138`, codex/image-studio. Изменения только в image-editor; StrictLib, mufoed и model-runtime не менялись. Коммит этого изменения не создавался.

## Изменения

- Open — обычная кнопка фиксированной ширины файловой группы с Popup::menu, той же ширины, что Save/Export. Старый menu_button игнорировал interact_size.x; проверено нативным снимком после исправления.
- Copy/Cut/Paste/Delete и Undo/Redo —32px векторные иконки с подсказками/shortcuts и accessibility labels. Варианты вставки доступны через отдельную рисованную стрелку: новый/текущий слой, глобальный режим Маска сохраняется. Независимость от символов шрифта, без emoji. Группа Правка не переносит подпись.
- Текстовые команды ленты —24px, Button font13, меньшие отступы. Слой/холст/трансформация/коррекция/отражения/настройки получили компактные иконки или строки с иконкой. Контекстные параметры и важные подписи сохранены, остальные панели не уменьшались.
- Палочка по-прежнему использует four-neighbor flood fill: сравнивает premultiplied RGBA каждого пикселя с цветом исходной точки, разница каждой компоненты не превышает допуск. Глобальный выбор цвета включает несвязанные области. Это выбор по цвету. Ранее допуск0 выбирал на фото лишь точные совпадения, часто незаметные при zoom<100%. Теперь отдельный color tolerance32; допуск заливки0 сохранён. После изменения допуска надо щёлкнуть снова.
- Видимое синее покрытие + контур, счётчик ненулевых пикселей и статус результата; переключатель подсветки в контексте инструмента. Очень маленькая область получает заметную рамку при уменьшенном масштабе. Покрытие — только UI, не запекается в пиксели/PNG/PSD; включено у палочки/глобального выбора. Исходный растр и маски не меняются, один Undo отменяет выбор.
- Исправлена реальная причина квадратных миниатюр: imageops::thumbnail получал side×side. Теперь Raster::thumbnail рассчитывает пропорциональные размеры, без увеличения исходного растра; raster/mask используют общий contain-rect, центрирование и2px inset в квадрат44px. Проверка выполняется через настоящий thumbnail, а не только геометрию готовой текстуры. Прозрачность сохраняется.
- Настройки имеют один фиксированный размер на все4 вкладки; размеры ограничены viewport. Содержимое прокручивается внутри, длинные пути не расширяют окно. Встроенный settings_ui остаётся пригодным для host. Окно по центру.

## Дополнение: Escape и смена слоёв (2026-10-22)

- Esc теперь снимает готовое выделение (в том числе мягкое) в режимах Растр/Маска; пиксели, маска ИИ и маски слоёв не стираются. Снятие выделения доступно в Undo. Esc также отменяет незавершённый жест и плавающую вставку, снимая восстановленное после отмены вставки выделение. Фокус кнопки/поля больше не блокирует Escape; диалог тоновой коррекции и трансформация сохраняют приоритет отмены.
- Готовое выделение относится к холсту: сохраняется при выборе/скрытии слоя. Исправлено сохранение незавершённого лассо при действиях со слоями: путь и режим совмещения очищаются, отпускание мыши не завершает старый жест.
- Pointer/key regressions: Escape для четырёх инструментов в обоих режимах, Undo/неизменность масок и пикселей, отмена вставки с существующим выделением, смена/скрытие слоя во время лассо. Палочка: выборка видимых слоёв исключает скрытый слой; выборка текущего слоя использует его растр независимо от видимости и меняет источник при выборе слоя.
- CPU demo all targets: **192 passed, 1 ignored, 0 failed**. Strict Clippy: PASS. Release demo,plakat-cudnn: PASS. Native screenshot smoke: exit0, artifacts/selection-escape-release.png. В этом дополнении production test suite повторно не запускалась; CUDA inference не проверялся.
- Логи: artifacts/selection-escape-tests.log, selection-escape-suite.log, selection-escape-clippy.log, selection-escape-release.log, selection-escape-launch.log. Актуальный EXE receipt: artifacts/selection-escape-release-receipt.json. Предыдущий UI02 receipt относится к сборке до этого дополнения.
