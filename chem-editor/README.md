# chem-editor — визуальный редактор химии

Нативный редактор химических формул на egui 0.35. Это самостоятельный
компонент интерфейса с демонстрационным приложением. Ядро не зависит от
StrictLib; опциональный feature `docx` подключает адаптер к библиотеке.

Редактор поддерживает два режима:

- **Структуры** — двумерные структурные формулы: атомы и связи с порядком
  (одинарная, двойная, тройная, ароматическая) и стерео (клин, штрихи);
  шаблоны колец; скелетное отображение (углерод без подписи); заряды атомов.
- **Реакции** — уравнения в нотации mhchem: виды (`\ce{2H2 + O2 -> 2H2O}`),
  коэффициенты, заряды, агрегатные состояния `(s) (l) (g) (aq)`, маркеры газа
  `↑` и осадка `↓`, стрелки (`->`, `<-`, `<->`, `<=>`, `=>`, `<=`) и условия
  над/под стрелкой.

Документ — это собственный формат JSON; SVG и DOCX являются производными
экспортами.

## Возможности

- палитра из 118 элементов как настоящая таблица Менделеева (18 столбцов,
  лантаноиды и актиноиды отдельными строками, цвет CPK);
- инструменты: выбор, перенос объекта, атом, связь, кольцо, ластик;
- выделение: щелчок по атому/связи/объекту, рамка по пустому месту (целая
  структура внутри рамки выделяется как объект), Shift добавляет к выделению,
  Ctrl+A выделяет всё;
- перемещение: перетаскивание атома двигает его, перетаскивание связи или
  объекта двигает всю структуру/реакцию; стрелки сдвигают выделенное (Shift —
  крупным шагом); сетка при переносе атомов (переключатель «Сетка»); при
  наведении подсвечивается будущая цель;
- дублирование выделения (Ctrl+D) и вписывание в окно (кнопка «Вписать», Ctrl+0)
  в один шаг отмены;
- выравнивание и равномерное распределение выделенных атомов
  (6 выравниваний, 2 распределения);
- буфер обмена фрагментов: Ctrl+C/X/V, JSON фрагмента в системном буфере;
- Undo/Redo (128 действий, 32 МБ) восстанавливает и выделение;
- инспектор: элемент, заряд и число водородов атома; порядок и стерео связи;
  счётчик выделенных объектов;
- молекулярная формула (нотация Хилла), молярная масса и Kekulé-SMILES
  выбранной структуры;
- сетка редактирования реакции (mhchem) с живым предпросмотром и полями
  условий стрелки;
- Undo/Redo (128 действий), панорамирование, масштаб, привязка углов 15°;
- сохранение/открытие JSON, автономный экспорт SVG и PNG (`raster`),
  экспорт/импорт DOCX;
- локализация English/Русский и любой внешний каталог, привязанные к
  экземпляру редактора.

## Запуск

```powershell
cargo +1.92.0 run -p chem-editor --features demo --bin chem-editor-demo
```

Готовый release-файл после сборки: `target/release/chem-editor-demo.exe`.

Выберите режим сверху, затем инструмент. В режиме структуры щёлкните на холсте,
чтобы поставить атом, и протяните от атома к атому, чтобы создать связь;
инструмент «Кольцо» штампует кольцо выбранного размера. Перенос — левой кнопкой,
панорамирование — средней кнопкой или колесом; Ctrl+колесо меняет масштаб.
Delete удаляет выделенное, Ctrl+Z отменяет, Ctrl+Y возвращает. Язык можно задать
через `CHEM_LANGUAGE=ru`.

## Встраивание

```rust,no_run
let mut editor = chem_editor::ChemEditor::sample();
// Внутри egui UI: editor.show(ui);
let json = editor.document().to_json()?;
let svg = editor.document().to_svg()?;
# Ok::<(), String>(())
```

`ChemEditor::new` принимает документ; `replace` заменяет его одной отменяемой
операцией. `document` отдаёт неизменяемую ссылку, а команды `add_structure`,
`add_atom`, `connect`, `bond_from`, `add_ring`, `add_reaction`,
`set_reaction_source`, `set_atom_element`, `set_bond`, `select`,
`delete_selected`, `undo` и `redo` позволяют управлять редактором из
приложения. `show` возвращает признак завершённого изменения, `revision`
позволяет отслеживать Undo/Redo и изменения модели.

Координаты — логические пиксели при 96 DPI. Модель использует стабильные ID,
ссылки на атомы вместо координат концов связи и явное происхождение объекта.
Один жест мышью — одна запись истории. Лимиты: 1000 объектов, 5000 атомов,
5000 связей, 2000 видов, 8 МБ JSON. Версия JSON — 1. SVG не содержит скриптов,
внешних ресурсов и foreignObject.

## Нотация mhchem

Читается и записывается поднабор: символы элементов с индексами, изотопные
прескрипты (`^{14}C`), группы в скобках (`(NH4)2SO4`), точечные гидраты
(`CuSO4.H2O`), заряды (`SO4^2-`, `Fe^3+`), состояния и маркеры. Числовой
множитель внутри гидрата (`CuSO4.5H2O`) не представим моделью и отвергается с
диагностикой.

## SMILES

`Structure::smiles` пишет детерминированную Kekulé-SMILES. Ароматические связи
нужно заменить чередующимися одинарными и двойными (`Long double`-шаблоны колец
создают их сразу); иначе экспорт возвращает диагностику. `molecular_formula` и
`molar_mass` учитывают неявные водороды по упрощённой таблице валентностей.

## Локализация

Каталоги `locales/en.json` и `locales/ru.json` включены в крейт. Язык привязан к
экземпляру редактора, без глобальной переменной. Ключи — исходные английские
сообщения (gettext-style); поддерживаются региональные теги (`ru-RU`), неполные
каталоги и английский fallback. Локализуются инструменты, инспектор, палитра (включая имена элементов),
подсказки, списки, диалоги демонстрации и собственные диагностики. Документ,
выделение и история при смене языка не изменяются.

Любой дополнительный язык задаётся плоским JSON-каталогом:

```rust,no_run
use chem_editor::{ChemEditor, Locale};
let french = Locale::new("fr").with_catalog(r#"{"Properties":"Propriétés"}"#)?;
let mut editor = ChemEditor::sample_with_locale(french.clone());
editor.set_locale(french);
# Ok::<(), String>(())
```

В демонстрации язык переключается кнопкой; начальный язык — `CHEM_LANGUAGE=ru`,
внешний каталог — переменная `CHEM_CATALOG` с путём к JSON.

## DOCX

`ChemDocument::to_docx` пишет структуры как редактируемый рисунок (каждый атом —
текстовое поле, каждая связь — линия с порядком и стерео: клин — залитый
треугольник, штрихи — набор линий; имена фигур хранят семантику), а реакции —
как абзац из runs с настоящими индексами и надстрочными знаками.
`ChemDocument::from_docx` читает обратно собственный вывод; чужие рисунки
приводят к отказу. Условия стрелки переносятся в строку сразу после стрелки.
Адаптер пользуется публичной моделью и общим writer StrictLib, без правок
библиотечных крейтов.


Тесты охватывают таблицу элементов, разбор и запись mhchem, вывод формулы, массы
и SMILES, круглый рейс JSON, разделяемый рендер (примитивы), экспорт SVG,

## Границы

Один холст, без вложенных объектов и произвольных путей. Водороды считаются по
упрощённой таблице валентностей; изотопы и стереохимия центра не хранятся.
Ароматические кольца хранятся как Kekulé-связи. Шаблоны колец создают
альтернированные связи. Маршруты связей прямые: пересечения устраняются только
вручную. Импорт DOCX рассчитан на вывод этого редактора. Метрики текста в
SVG/примитивах приближённые (средняя ширина символа), поэтому перенос строк не
поддерживается.
